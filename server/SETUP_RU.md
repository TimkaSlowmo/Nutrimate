# Как включить настоящий ИИ для Нутрика (≈10 минут, бесплатно)

Нутрик уже умеет отвечать без интернета. Чтобы он стал **настоящим ИИ** для всех, кто скачал приложение,
нужен бесплатный аккаунт Cloudflare. Карта не нужна, платный тариф **не включай**.
Всё остальное (сервер, загрузка, адрес в приложении, сборка) сделает GitHub сам.

---

## Шаг 1. Регистрация на Cloudflare (3 мин)
1. Открой **https://dash.cloudflare.com/sign-up** → введи почту и пароль → подтверди почту из письма.
2. Если спросят про план — выбери **Free** (бесплатный). Сайт/домен добавлять **не нужно** — пропусти.
3. Слева в меню открой **Compute (Workers)** → **Workers & Pages**.
   Если Cloudflare попросит выбрать поддомен *workers.dev* — придумай любое короткое слово (например, `timka`) и сохрани.
   Если он предлагает создать первый воркер — можно просто закрыть, создавать ничего не надо.

## Шаг 2. Account ID (1 мин)
1. На той же странице **Workers & Pages** справа есть блок **Account details** → строка **Account ID**.
   (Или: нажми на название аккаунта вверху слева → Account home → `⋯` возле аккаунта → **Copy account ID**.)
2. Нажми значок копирования. Это длинная строка из букв и цифр, например `a1b2c3…`. Сохрани её в заметки.

## Шаг 3. API Token (3 мин)
1. Открой **https://dash.cloudflare.com/profile/api-tokens** → **Create Token**.
2. Найди шаблон **Edit Cloudflare Workers** → **Use template**.
3. В списке **Permissions** нажми **+ Add more** и добавь:
   - `Account` · `Workers AI` · `Edit`
   - (необязательно) `Account` · `Workers KV Storage` · `Edit`
4. **Account Resources**: `Include` → твой аккаунт. **Zone Resources**: `All zones` (как в шаблоне).
5. Внизу **Continue to summary** → **Create Token**.
6. Скопируй токен (он показывается **один раз**!). Никому его не отправляй и нигде не публикуй.

## Шаг 4. Два секрета в GitHub (2 мин)
1. Открой **https://github.com/TimkaSlowmo/Nutrimate/settings/secrets/actions**
   (Репозиторий → **Settings** → слева **Secrets and variables** → **Actions**).
2. **New repository secret**:
   - Name: `CLOUDFLARE_API_TOKEN` → Secret: токен из шага 3 → **Add secret**.
3. Ещё раз **New repository secret**:
   - Name: `CLOUDFLARE_ACCOUNT_ID` → Secret: Account ID из шага 2 → **Add secret**.

Имена пиши точно так, большими буквами.

## Шаг 5. Запуск (1 мин)
1. Открой **https://github.com/TimkaSlowmo/Nutrimate/actions/workflows/server.yml**
2. Справа **Run workflow** → зелёная кнопка **Run workflow**.
3. Через 1–2 минуты появится зелёная галочка ✅. В итоге запуска будет строка
   `🤖 Nutrik AI: https://nutrimate-nutrik.<твой-поддомен>.workers.dev`.
4. GitHub **сам** впишет этот адрес в приложение и соберёт новый NutriMate.ipa (ещё ~3 мин).
   Скачай его как обычно со страницы https://github.com/TimkaSlowmo/Nutrimate/releases/tag/ios-latest → Sideloadly.

Готово! В чате с Нутриком под шапкой будет написано **Smart AI · online**.

## Частые вопросы
- **Это точно бесплатно?** Да. Workers Free + бесплатный дневной лимит Workers AI (≈10 000 «нейронов» в день —
  это сотни коротких ответов). Когда лимит кончается, Cloudflare просто отказывает до завтра, а приложение
  незаметно переключается на офлайн-Нутрика. Денег не спишут: карту не привязываем, Paid-план не включаем.
- **Сколько может писать один человек?** До 30 сообщений ИИ в день на телефон (защита от спама).
  Команды вроде «add milk to shopping list» и «I don't like onion» работают всегда и не тратят лимит.
- **Что уходит на сервер?** Только имя, список продуктов со сроками, калории за сегодня, нелюбимые продукты
  и последние ~10 сообщений чата. Почта и вес не отправляются. В Profile можно выключить «Smart Nutrik».
- **Красный крестик в шаге 5?** Открой запуск → шаг «Deploy». Частые причины:
  - *Authentication error* — токен скопирован не целиком или без нужных прав → создай новый (шаг 3) и замени секрет.
  - *You need to register a workers.dev subdomain* — сделай пункт 3 из шага 1 и запусти снова.
  Если не получается — напиши ошибку в `ios/BUILD_ERRORS.md`, ночной агент разберётся.
