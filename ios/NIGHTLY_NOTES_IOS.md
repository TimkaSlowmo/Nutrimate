# NutriMate iOS — журнал ночного агента

## Как установить
1. https://github.com/TimkaSlowmo/Nutrimate/releases/tag/ios-latest → скачать **NutriMate.ipa**.
2. Sideloadly (или AltStore) → свой Apple ID → iPhone по кабелю. Бесплатный Apple ID: переустанавливать раз в 7 дней.
3. Переустановка поверх сохраняет данные (файл `Application Support/nutrimate.json`).

## Устройство
- SwiftUI, iOS 17+, Swift 5 mode, без сторонних библиотек. Проект — XcodeGen (`ios/project.yml`), сборка — `.github/workflows/ios.yml`
  (macos-15, неподписанный .ipa → релиз `ios-latest` + artifact).
- Данные продуктов/рецептов: `NutriMate/Resources/foods.json` ← `python3 tool/export_data.py` (из lib/main.dart). Не править вручную.
- Иконка: `python3 tool/make_app_icon.py`.
- Хранение: `AppStore` (ObservableObject) → JSON, мягкое декодирование (новые поля не ломают старые сохранения),
  битый файл копируется в `nutrimate.broken-<время>.json`, а не затирается.
- Версия: с 12.11 по просьбе владельца нумерация продолжает DartPad-версии — текущая **v16**, дальше 17, 18…
  `ios/VERSION` + `CFBundleShortVersionString/CFBundleVersion` в project.yml (+1 за ночь).

## 2026-11-12 (день) · v16 (бывшая v10) — новый профиль, честные действия ИИ, переводы названий

  3 крупные цифры (спасено, дни без отходов, деньги), полоса медалей. Группы как в «Настройках» iOS (иконки в цветных
  квадратиках): Body & goal, Progress, Nutrik, Notifications, Data (сброс красным + подтверждение). Экраны Edit profile
  (имя, аватар, пол, возраст, рост, вес + график, активность, цель, живая цель ккал), Medals (сетка с описаниями),
  Skipped in recipes. Поля `Profile.joined`, `Profile.avatar` — мягко; для старых сохранений дата = самая ранняя запись.
  XP = съел×2 + спас×10 + приготовил×15 + заморозил×5 + поделился×10 + купил×3 + медали×25; порог уровня 50·(n−1)².
- **Честные действия (жалоба 5)**: клиент шлёт `actions:true` и `context.language`; сервер добавляет протокол

  просьбу-действие — «не получилось, я ничего не менял, попробуй так: …». Старые клиенты (без actions) — как раньше.
  Smoke-тест: «add 2 eggs to my fridge» → add_fridge Eggs ×2 ✅; казахский путал морозилку — сервер поправляет по словам.
- **Языки (жалоба 3, начало)**: `tool/translations_src.txt` (English|Русский|Қазақша) → foods.json `ru`/`kk`;
  155 популярных продуктов; поиск находит «яйца», «жұмыртқа». Интерфейс пока английский.

## 2026-11-12 (утро) · v9 — жалобы владельца 1 и 2 закрыты, 5 — частично
- **Лаги (жалоба 1)**: главная причина — живой фон был Canvas + blur(50) на весь экран 20 раз в секунду, а под каждой стеклянной
  карточкой `.ultraThinMaterial` заново размывал этот меняющийся фон каждый кадр. Теперь: фон — 4 радиальных градиента
  («уже размытые» пятна), движутся offset/scale через repeatForever (GPU, body не пересчитывается); карточки, строки
  холодильника, чипы и пузыри чата — полупрозрачная заливка с бликом вместо Material, тень только у формы; Material остался
  только у таб-бара, тоста и туториала. ProMotion: `CADisableMinimumFrameDurationOnPhone`. Нутрик: TimelineView 60 Гц и
  пауза, когда не виден/приложение свёрнуто; невидимый Нутрик-помощник раньше анимировался всегда — теперь не рисуется.
  Кэш `rankedRecipes` и строк холодильника (пересчёт только при изменении данных).
- **Замер fps**: `-uiShot -fps` (App/FPSProbe.swift) — 2.5 с после запуска сам прокручивает главный список 6 с вниз-вверх,
  считает кадры CADisplayLink, пишет Documents/fps.txt; ios-screens.yml гоняет home/fridge/search/recipes, итог — в README ветки.
- **Складывание (жалоба 2)**: у партии новое поле `qty` (мягко: нет → 1). Строка холодильника = продукт + место
  (`PantryGroup`): «🥚 Eggs ×10», партии с разными сроками → одна строка со сроком ближайшей и «2 batches». Партии со сроком
  ±1 день сливаются. Съел/выбросил/поделился — 1 штука из самой старой партии; «Freeze all» — вся строка; −/＋ в карточке
  (исправление без статистики); смена места переносит строку и складывает. При запуске старые сохранения объединяются
  (`AppStore.normalized`, срок — более ранний, ничего не теряется). Медали, «in fridge», деньги под угрозой, Eco — по штукам.
- **Честные действия (жалоба 5, частично)**: `NutrikActions.swift` — «add 2 eggs to fridge», «добавь 2 яйца в холодильник»,
  «тоңазытқышқа 2 жұмыртқа қос», «съел банан», «выбросил кефир», «заморозь курицу», «I bought 6 eggs»: действие выполняется,
  ответ по факту (сколько стало); нет продукта — «не нашёл, ничего не менял» + похожие; нет в холодильнике — честно.
  ~80 русских/казахских названий продуктов понимаются по основе слова. Такие сообщения не уходят в ИИ. Ответ ИИ с
  «добавил / I've added…» отбрасывается на телефоне (офлайн-ответ вместо него).
- Сервер: правило «ты не можешь менять данные», ответ на языке сообщения (или context.language), `guarded`-замена ложного
  «добавил» на честную подсказку (en/ru/kk), qty в холодильнике, +12 тестов, smoke-тест на русском в server.yml (прошёл: «не могу добавлять…»).
- База: 1424 продукта, 118 рецептов.
