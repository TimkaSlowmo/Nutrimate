# NutriMate iOS — журнал ночного агента

## Как установить
1. https://github.com/TimkaSlowmo/Nutrimate/releases/tag/ios-latest → скачать **NutriMate.ipa**.
2. Sideloadly (или AltStore) → свой Apple ID → iPhone по кабелю. Бесплатный Apple ID: переустанавливать раз в 7 дней.
3. Переустановка поверх сохраняет данные (файл `Application Support/nutrimate.json`).

## Устройство
- SwiftUI, iOS 17+, Swift 5 mode, без сторонних библиотек. Проект — XcodeGen (`ios/project.yml`), сборка — `.github/workflows/ios.yml`
  (macos-15, неподписанный .ipa → релиз `ios-latest` + artifact).
- Данные продуктов/рецептов: `NutriMate/Resources/foods.json` ← `python3 tool/export_data.py` (из lib/main.dart). Не править вручную.
- Иконка: `python3 tool/make_app_icon.py`.
- Хранение: `AppStore` (ObservableObject) → JSON, мягкое декодирование (новые поля не ломают старые сохранения),
  битый файл копируется в `nutrimate.broken-<время>.json`, а не затирается.
- Версия: `ios/VERSION` + `CFBundleShortVersionString/CFBundleVersion` в project.yml (+1 за ночь).

## 2026-11-07 · v1 (первая ночь)
- Создан проект, workflow и релиз `ios-latest` (Xcode 16.4, macos-15, сборка ~1.5 мин, .ipa ≈ 0.8 МБ). Скомпилировалось с первой попытки.
- Экраны: регистрация с Нутриком (3 шага + демо-продукты), Home (калории-кольцо, «Use these first», статистика,
  покупки, дневник), Fridge (фильтр по месту, свайп «съел»/«заморозить»/«в мусор» с причиной, карточка продукта),
  Search (категории, «Popular in Almaty», быстрый «＋», карточка добавления, долгое нажатие — записать съеденное),
  Recipes (ранжирование по холодильнику и «горящим» продуктам, фильтры, шаги-чеклист, «I cooked it»),
  Profile (параметры, цель ккал, вес, Eco-цифры, медали, сброс данных).
- Иконка приложения — лицо Нутрика на бордовом фоне.
- База: 1246 продуктов, 91 рецепт.

## 2026-11-09 · v3 (ночь 3)
- **Нутрик ожил**: новые настроения run (ножки и ручки мелькают, пыль, капелька пота), fall (глаза-крестики, звёздочки),
  eating с эмодзи продукта в лапке (подносит ко рту, крошки), talk (рот двигается), cheer (руки вверх, искорки).
- **Сценки** (`NutrikBuddy`, над таб-баром слева): съел/приготовил → выбегает и ест этот продукт; выбросил → спотыкается,
  падает, встаёт грустный; заморозил/поделился → радуется. Тап — убегает. Выключатель: Profile → Nutrik → «Nutrik reacts»
  (новое поле `nutrikBuddy`, мягкое декодирование).
- Нутрик неуклюжий: по тапу иногда падает. На Home и в туториале «говорит», когда меняется реплика; тап по облачку на Home — советы.
- Home: карточка **Rescue recipe / Recipe of the day** (рецепт с продуктами, которые скоро испортятся). Уведомление 9:00 предлагает рецепт.
- База: 1301 продукт, 101 рецепт. Сборка зелёная с первой попытки (2.5 мин).

## Бэклог iOS
1. AI-чат с Нутриком (rule-based, как в вебе).
